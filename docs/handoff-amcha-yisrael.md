### רקע — למה זה קורה עכשיו

המפלגה **לא קיימת בכלל** ב-`parties.json` הנוכחי (12 מפלגות, בלי עמך ישראל). זו המשימה שלך לתקן.

### שלב 2 — הזרקה בפועל

**זו לא ריצת מחקר-בלבד — בניגוד לריצה הקודמת (22.9), הפעם באמת להזריק.**

1. הוסף אובייקט מפלגה מלא ל-`src/data/parties.json` (`id: "amcha_yisrael"`, `seats: 4`, ושאר השדות לפי המתודולוגיה של שלב 0.4).
2. כלול לפחות מועמד מקום 1 (עופר וינטר) במערך `candidates`; הוסף מקומות 2–4 רק אם יש להם בסיס עובדתי מאומת.
3. `npm run update-scores` — הרץ מחדש.
4. עדכני תקינות: `node -e "['questions','parties','anchor-votes'].forEach(f => JSON.parse(require('fs').readFileSync('./src/data/'+f+'.json','utf8')))"` , `npx tsc --noEmit -p .`, `npm run build`, `npm run lint` — כולם חייבים לעבור נקי.
5. בדיקת דפדפן קצרה (`npm run dev`) — ודא שהמפלגה החדשה מופיעה בתוצאות בלי לשבור כלום.
6. עדכן את `docs/2026-09-22-update-research.md` (או צור תוספת מתוארכת) לתעד שההזרקה בוצעה בפועל — כדי שלא ייווצר שוב הפער התהליכי שתועד שם בסעיף 1.9 (שינויי נתונים בלי תיעוד בפייפליין השבועי).

### הערות חשובות

- **אל תדחוף (push) לגיט.** commit מקומי בלבד, ותדווח למשתמש. זה כלל קבוע בפרויקט.
- אם משהו לא ברור/שנוי במחלוקת (למשל סדר הרשימה המדויק למקומות 2-4, או מספר מנדטים סופי אחר מ-4) — עצור ותעד כפער לביקורת אנושית, אל תנחש. זה עקרון-העל של הפרויקט.
- הפרויקט דובר עברית — כתוב את כל התוכן (שמות שדות ב-JSON נשארים באנגלית לפי הקונבנציה הקיימת, אבל טקסט חופשי — `notes`, `sources`, ציטוטים — בעברית).
