### שלב 1 — סקירה סופית של כל הפרויקט

1. `git status` — הבן בדיוק מה השתנה/נוסף מאז הקומיט האחרון (`848a85f`).
2. **חשוב:** בפרויקט הזה יש כל הזמן קבצים לא-קשורים של פיצ'ר אחר בעבודה, שאסור לגעת בהם או לכלול בקומיט: `one-pager-itonaim.pdf`, `one-pager.docx`, `פרומפט פיצ'ר השוואה עם חבר.md`, ותיקיית `שיווק/`. אם הם עדיין untracked — השאר אותם ככה. **הוסף לקומיט רק קבצים שקשורים בבירור לעדכון הנתונים/מחקר המועמדים** (`src/data/*.json`, `docs/candidate-research/*.md`, `docs/*update-research*.md`, `docs/handoff-*.md`, וכל קובץ קומפוננטה שבאמת נערך כחלק מהעבודה הזו).
3. אמת תקינות: `node -e "['questions','parties','anchor-votes'].forEach(f => JSON.parse(require('fs').readFileSync('./src/data/'+f+'.json','utf8')))"`.
4. `npx tsc --noEmit -p .`, `npm run build`, `npm run lint` — כולם חייבים לעבור נקי. אם משהו נכשל — תקן לפני שתמשיך, אל תדלג.
5. `npm run update-scores` — הרץ ווודא שאין הפתעות (אמור להיות "0 שינויים" אם כל הריצות הקודמות כבר הריצו אותו כראוי; אם יש שינויים לא-צפויים — בדוק למה לפני שתמשיך).
6. בדיקת שפיות מהירה בדפדפן (`npm run dev`): פתח את האפליקציה, ודא שאין שגיאות קונסולה, ושמפלגת "עמך ישראל" מופיעה ברשימת המפלגות/בתוצאות בלי לשבור כלום.
7. עבור על `git diff` של `src/data/parties.json` בעין — ודא שאין שינוי לא-מוסבר (מספר שהשתנה בלי סיבה מתועדת, שדה שנעלם).

### שלב 2 — הכנה לקומיט

1. `git add` רק לקבצים הרלוונטיים (ר' שלב 1.2) — **אל** תשתמש ב-`git add -A`/`git add .`.
2. כתוב הודעת קומיט תמציתית שמסבירה את ה-*why*, בעברית או אנגלית לפי הסגנון הקיים בפרויקט (ר' `git log`), ומזכירה את שני השלבים שקדמו (הוספת עמך ישראל + ביקורת האיכות שתיקנה X דברים — מלא את X לפי מה שאתה מוצא בפועל בדוחות/בקוד).
3. סיים את הודעת ה-commit בשורות הייחוס:
   ```
   Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
   ```

### שלב 3 — קומיט ודחיפה

1. `git commit` עם ההודעה שהכנת.
2. `git status` — ודא שהקומיט הצליח ושלא נשאר כלום רלוונטי לא-מקומיט.
3. `git push` — **בוצע באישור מפורש מראש של המשתמש, ספציפית לריצה הזו.** זה משנה אתר לייב (Vercel) — ודא ששלב 1 (build/lint/tsc/דפדפן) באמת עבר נקי לפני שאתה מגיע לכאן.
4. `git log --oneline -3` אחרי הדחיפה, כדי לאשר שהיא הצליחה ושה-remote מעודכן.

### דוח סופי

כתוב בעברית: אילו קבצים נכללו בקומיט, מה הודעת הקומיט, תוצאת כל בדיקות השלב 1, ואישור שהדחיפה הצליחה (כולל ה-hash הסופי). אם משהו בשלב 1 נכשל ולא תיקנת אותו במלואו — **אל תדחוף**, דווח מה נכשל ועצור.
